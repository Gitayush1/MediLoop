# MediLoop – AI Pipeline Documentation

## 1. Overview

The MediLoop AI Pipeline automates the process of parsing paper or digital prescription documents (images/PDFs) into structured, validated medication definitions.

```
Document Upload (JPG/PNG/PDF)
         │
         ▼
  File Validation
         │
         ▼
    OCR Provider
(Text extraction from image)
         │ raw text
         ▼
    LLM Provider
(OpenAI GPT-4 / Mock Provider)
         │ structured JSON
         ▼
  Zod Schema Validation
         │
         ▼
  Confidence Assessment
(Score 0.0 – 1.0 per field)
         │
         ▼
Prescription Medicine Record
(Unconfirmed state)
         │
         ▼
User Confirmation & Review
```

---

## 2. Abstraction Interfaces

The pipeline is built using pluggable provider interfaces (`apps/server/src/modules/ai/providers`):

```typescript
export interface OCRProvider {
  extractText(fileBuffer: Buffer, mimeType: string): Promise<string>;
}

export interface LLMProvider {
  extractPrescription(ocrText: string): Promise<PrescriptionExtractionResult>;
  explainMedication(context: MedicationContext): Promise<string>;
}
```

---

## 3. Provider Implementations

- **`OCRProvider`**: Uses Tesseract / Cloud Vision API in production, with a mock fallback in development/test.
- **`LLMProvider`**: Uses OpenAI GPT-4o JSON mode with strict system prompts to output JSON matching `PrescriptionExtractionResult`.

---

## 4. Confidence Scoring & Safety Rules

- Every extracted medicine receives a confidence score between `0.0` and `1.0`.
- **Low Confidence (< 0.7)**: Highlighted in red in the mobile review screen.
- **Safety Rule**: Creation of schedules **always requires explicit user confirmation**. The AI pipeline never creates active medication schedules automatically without user verification.
- **Disclaimers**: Explanations generated by the LLM strictly exclude diagnostic or dosage advice and include mandatory healthcare disclaimers.
